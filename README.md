# Web Development Project

A small collection of HTML/CSS demos with animated hearts and a Valentine card effect. This repository contains two example pages that demonstrate CSS-only animations and simple interactive styles.

---

## 📁 Files

- `ValentineDay.html` — An interactive Valentine card that uses `Valentine.css`. Features a book-like cover that flips on hover, a small animated heart, blinking eyes, and decorative text.
- `beat.html` — A standalone page that draws and animates a heart using inline CSS (pseudo-elements and keyframes).
- `Valentine.css` — Styles for `ValentineDay.html` (animations, layout, and visual details).

---

## ▶️ Preview / Run

1. Open `ValentineDay.html` or `beat.html` in your browser (double-click or use "Open with Live Server").
2. Optionally serve the folder with a local server for a more realistic environment (e.g., `python -m http.server` or `npx http-server`).

---

## ✨ Features

- Pure HTML & CSS — no JavaScript required
- CSS animations: heartbeat, blinking eyes, cover flip, bulge effect
- Creative use of pseudo-elements to form shapes (hearts, eyes)
